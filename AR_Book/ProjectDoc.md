# AR Book – Unity AR Foundation Project

An interactive AR experience built with Unity, AR Foundation, and ARCore/Vuforia. Scans book pages or image targets to display 3D models and animations in the real world.

### Key Features
- Image-based target tracking
- Real-time 3D object placement
- Interactive animations
- Android AR support

### Skills
Augmented Reality · Image Tracking · Unity Development · 3D Interaction
