# AR/VR Workshop
A collection of four Unity-based AR/VR experiences developed during the IOFT workshop, exploring augmented reality, virtual reality, image tracking, physics, and interactive environments.

## Projects :
1. AR Book
An interactive AR experience that uses image tracking to display 3D models and animations on book pages.
2. VR Gun and Barrel Game
A VR shooting prototype featuring virtual gun interactions, aiming, and target-based gameplay.
3. Physics-Based VR Ball Game
A VR prototype exploring physics-driven ball movement, object manipulation, and collision interactions.
4. VR Roller Coaster Ride
An immersive VR roller coaster simulation exploring virtual environments and motion.

### Technologies
Unity · C# · AR Foundation · AR · VR · Physics Simulation

### Learning Outcomes
- AR image tracking and 3D object placement
- VR interactions and immersive environments
- Physics-based gameplay
- Unity development fundamentals

> Built during the IOFT AR/VR Workshop, November 2025.
